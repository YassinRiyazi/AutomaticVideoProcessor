Time series by tilt angle and repetition

Hover a curve to highlight that run. Click a legend entry to hide/show it, double-click to isolate it. Drag to zoom, double-click the plot to reset.

Degradation across repetitions

One value per run: a summary statistic of the selected quantity, computed on the unsmoothed data inside a common analysis window, so that every run is compared over the same stretch of time or of surface. Frames are weighted by the distance (or time) they cover, so slow parts of a run are not over-counted. Regions outside the window are greyed out in the time-series plot.

Trend per tilt angle · dashed = least-squares fit over repetitions
Tilt × repetition overview · empty = not recorded, ⚠ = flagged run
Trend statistics

Slope ± standard error from an ordinary least-squares fit of the per-run value against repetition number (only with ≥ 4 runs). “Rel.” = slope relative to the fitted value at the first repetition.
